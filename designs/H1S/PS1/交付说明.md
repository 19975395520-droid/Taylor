# 反制盾交互原型

本目录保存反制盾网页交互原型源码（2026-10-26）。

## 本地运行

安装 Node.js 22.12 或更高版本，在本目录运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/?device=shield 。

## 内容

包含探测、历史、统计、白名单和设置界面，以及当前模拟交互、图片及报告导出依赖。

这是前端演示，示例数据不代表真实设备状态；未连接真实设备和业务接口。
