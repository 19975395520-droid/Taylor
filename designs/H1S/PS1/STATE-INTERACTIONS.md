# 状态与告警联动

- 设备状态可展开查看探测、反制、解码程序；目前为前端演示状态，未接设备服务。
- 路线入口使用高德官方 URI 导航服务，携带所选终点，经纬度使用现有演示数据，坐标顺序为经度、纬度。移动端可唤起高德，PC 端打开网页。实际数据接入时需确认 GCJ-02 坐标系。
- 添加信任打开白名单表单，型号可编辑，SN 与当前目标绑定。保存后按 SN 更新或新增授权；取消信任停用授权，保留记录。
- 白名单页面与告警详情共享数据；白名单和高度阈值使用 localStorage 保存，刷新和设备模式切换后可恢复。此功能不是服务器同步。
- 高度阈值以米存储，参数设置切换英尺时换算显示。详情显示米值；只有飞行高度严格大于阈值时变红并显示告警图标，等于时不告警。
- 详细参数收紧行列间距，不再折叠。

验证：类型检查和生产构建通过。浏览器验证状态展开/收起、添加信任、白名单回显、取消信任；阈值120→200时126m解除告警，阈值126时不告警，恢复120后重新告警。高德链接参数已检查，未执行真实位置导航。
