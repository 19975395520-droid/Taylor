# 直接打开的交互原型

下载同目录的「反制盾交互原型.html」，用新版 Chrome 或 Edge 打开。可从 GitHub 文件页点击 Download raw file 下载；GitHub 的代码页不会运行 HTML。

文件内嵌页面样式、交互脚本、FPV与无人机图片、PDF/Word报告导出组件，无需 npm 或开发服务器。默认打开反制盾界面。

菜单交互已在本地浏览器验证，包括探测首页、历史和设置切换。示例设置存在浏览器本地；设备状态和数据为演示。真实设备操作仍需要后台接口。

此文件为 HTML 网页原型，不是 Figma 原生 .fig 文件，不能直接拖入 Figma 获得设计图层。Figma 文件尚未完成。

原型保留源项目的中文说明书入口；离线版将英文附件入口指向内嵌中文说明书。
