# Taylor

用于日常 Codex 设计、页面原型和交互探索的轻量工作区。使用原生 HTML、CSS 和 JavaScript，无需安装第三方依赖。

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在本机浏览器打开端口 8000。云环境中可使用 HTTP 请求验证页面，不依赖公开预览。

## 与 Codex 协作

描述页面用途、目标用户、视觉风格和交互需求，也可以提供参考图片。默认从 `index.html`、`styles.css` 和 `script.js` 开始修改。

示例：为个人作品集设计一个简洁首页，使用暖白背景，包含项目卡片、个人介绍和联系入口。

## 检查

```sh
node --check script.js
curl --fail http://127.0.0.1:8000/
```

提交前检查浏览器布局、键盘操作和窄屏显示。当前项目未配置自动化浏览器测试。
